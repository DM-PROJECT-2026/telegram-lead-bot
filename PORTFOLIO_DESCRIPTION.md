# Telegram-бот для сбора заявок

Telegram-бот на Python для автоматизированного сбора клиентских заявок. Пользователь заполняет пошаговую форму, проверяет введённые данные и подтверждает отправку. Заявки сохраняются в SQLite, а администратор сразу получает уведомление в Telegram.

## Реализовано

- пошаговая анкета с проверкой номера телефона;
- подтверждение или повторное заполнение заявки;
- SQLite-хранилище с датой создания;
- уведомления администратора;
- защищённые команды администратора `/leads` и `/stats`;
- развёртывание на Ubuntu-сервере через systemd;
- автозапуск после перезагрузки;
- ежедневные резервные копии и уведомление о критическом сбое;
- конфигурация через `.env`, без секретов в коде.

## Стек

Python 3, python-telegram-bot, SQLite, systemd, GitHub, Ubuntu.
