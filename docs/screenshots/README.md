# Скриншоты для портфолио

Добавьте в эту папку два скриншота с тестовыми, не настоящими персональными данными:

1. `bot-dialog.png` — заполнение заявки и успешное подтверждение в Telegram.
2. `database.png` — строка заявки в SQLite Viewer.

Перед публикацией проверьте, что на изображениях нет токенов, паролей, публичных IP-адресов, реальных телефонов, username или Telegram ID.
