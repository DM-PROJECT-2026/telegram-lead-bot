# Политика обработки данных

Бот получает имя, номер телефона, страну и комментарий пользователя только для обработки заявки и связи по ней.

Данные сохраняются в локальной SQLite-базе владельца бота. Доступ к ним имеет только владелец проекта. Данные не передаются третьим лицам, кроме случаев, предусмотренных применимым законодательством.

Пользователь может прекратить заполнение заявки командой `/cancel`. По вопросам удаления или уточнения данных пользователь обращается к владельцу бота через Telegram.

Это демонстрационный проект. Перед использованием в коммерческом проекте текст политики необходимо адаптировать под фактические процессы обработки данных и применимое законодательство.
